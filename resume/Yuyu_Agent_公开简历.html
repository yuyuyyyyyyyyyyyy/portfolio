01 · Windows 桌面求职 Agent｜独立开发

Python · 大模型 HTTP API · JSON 校验 · Windows UI Automation · SQLite

  • 处理规模与职责：本地数据库保存 2,400+ 条按岗位身份去重的处理记录；把岗位读取、门槛检查、模型分级、项目证据匹配、桌面执行与结果回读拆成可检查的步骤。
  • 判断可信度：模型返回结构化 JSON，程序校验字段与硬门槛；将“明确冲突”“待补充信息”“项目证据”分开保存，匹配不足的岗位转人工判断。
  • 失败恢复：核对岗位卡片、详情与聊天对象；读取超时保留检查点，页面错位立即停机。发送后回读会话，仅在观察到对应消息时记为已发送；不确定状态不自动重试，避免重复沟通。
